编辑模式 · 重设计提案

同一块画面，五种分步向导。

现在的编辑器是「列表 + 检查器」，一上来就把所有元素铺给你。这五个方案都改成分步向导——把换肤拆成基调 → 配色 → 布局 → 预览四步，一次只问一件事。下面每个方案都叠在同一块播放器画面上，方便你只盯交互形态做横向对比。

统一四步：基调·配色·布局·预览 深黑 + ShikiiN 蓝 每步可撤销 / 跳回 最后一屏实时预览 + 保存 / 另存
方案 01

顶部步骤条

Stepper · 最稳妥

经典横向步骤条钉在顶部，走到哪一步一眼可见。中间是当前步的内容，右下角「上一步 / 下一步」推进。零学习成本，谁都会用。

  • ① 基调 ② 配色 ③ 布局 ④ 预览，完成的步骤打勾、可点回
  • 内容区始终居中，每屏只聚焦一类选择
  • 顶/底栏保留真实画面，改动隔着内容也能瞥见
适合： 想要最不会迷路、最像「设置向导」的稳妥路线。

方案 02

侧栏向导 + 实时预览

Rail & Live · 最专业

左侧竖向步骤导航，中间是当前步的选项，右侧大半屏是真实播放器——每改一下，预览立刻变。所见即所得，信息密度高。

  • 竖向步骤带连接线，进度像时间轴一样直观
  • 改色 / 调布局右侧实时刷新，不用来回切
  • 步骤、选项、预览三栏分工清楚
适合： 爱折腾细节、想边调边看效果的进阶用户。

方案 03

聚光卡片

Spotlight · 最沉浸

画面整体压暗虚化，中央只浮一张卡片，一次问一件事。底部圆点显示进度，像 App 第一次打开的引导。干净、专注、不被打扰。

  • 背景虚化真实画面，注意力全在当前选择上
  • 大色块 / 大按钮，触屏与远距离也好点
  • 圆点进度 + 「开始 / 下一步」，节奏轻快
适合： 追求简洁仪式感、不想看到一堆控件的人。

方案 04

胶片格进度

Filmstrip · 最契合主题

底部一条胶片格当进度，每格是一步的缩略效果，当前格放大高亮。呼应播放器 / 动漫的「帧」语言，任意格可点击跳转，自由度高。

  • 胶片隐喻贴合 ShikiiN，编辑像在剪辑时间轴
  • 每格预览该步成品，跳步不靠记忆
  • 当前格放大 + 蓝描边，位置感强
适合： 喜欢非线性、想随时跳回某一步微调的人。

方案 05

教练气泡

Coach Marks · 最上下文

不离开真实界面，向导用引导气泡逐个指向要改的部件：先框住标题栏、再框控制栏……气泡里就地改，边走边所见即所得，几乎没有模式切换。

  • 高亮当前部件、压暗其余，明确「现在改这里」
  • 气泡内嵌选项，改完点「下一处」
  • 始终站在成品上，没有抽象的元素列表
适合： 想直接在真实播放器上、被手把手领着改的人。
